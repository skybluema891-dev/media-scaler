## Media Scaler 1.2.6 の変更

- ファイル一覧、設定、比較プレビュー、進捗表示をチャコール基調で統一しました。初めて起動したときはダーク表示になり、保存済みのライト表示とOSに合わせる設定は引き継がれます。
- Windowsで処理を開始・終了した際に、JPEG品質の読み上げ情報が欠ける問題を修正しました。比較プレビューでは、境界の位置を矢印キーで変え、元画像が占める割合を読み上げで確認できます。
- Windowsでは日本語や空白を含む深いフォルダにインストールしても、同梱AIワーカーの依存ファイルを読み込めるようにしました。GPU用ツールのパス上限を超える処理はCPUで続行します。
- WindowsのIntel Quick Syncで小さな解像度のH.265動画を書き出す際の不具合を修正しました。CPUエンコーダーの特定の異常終了では、並列処理を抑えて一度再試行します。

WindowsにはセットアップEXE、Apple Silicon搭載Macにはarm64のDMG、Intel搭載Macにはx86_64のDMGを使用してください。更新通知の「ダウンロード」は、利用中のOSとアーキテクチャに対応するファイルを開きます。
